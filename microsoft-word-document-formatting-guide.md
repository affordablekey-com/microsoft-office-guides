# Microsoft Word Document Formatting Guide

Good formatting makes a document easier to read, understand, and edit.

This guide covers simple Microsoft Word formatting techniques for everyday documents.

## 1. Choose a Clear Font

Use a simple and readable font for most documents.

Common choices include:

- Aptos
- Calibri
- Arial
- Times New Roman

Keep the font style consistent throughout the document unless a different style has a clear purpose.

## 2. Use Appropriate Font Sizes

A common approach is:

- Document title: 18–24 pt
- Main headings: 14–16 pt
- Body text: 10–12 pt

The exact size can vary depending on the document type.

## 3. Use Heading Styles

Instead of manually changing every heading, use Word's built-in heading styles.

1. Select the heading.
2. Open the **Home** tab.
3. Choose a style such as **Heading 1**, **Heading 2**, or **Heading 3**.

Using heading styles also makes it easier to create a table of contents.

## 4. Adjust Paragraph Spacing

Good spacing improves readability.

To change paragraph spacing:

1. Select the text.
2. Open the **Layout** tab.
3. Adjust **Before** and **After** spacing.
4. Choose a suitable line spacing option.

Avoid adding many blank lines to create space between paragraphs.

## 5. Use Bold and Italic Carefully

Use **bold** to highlight important words or headings.

Use *italic* for emphasis or specific terms when appropriate.

Avoid formatting large sections with bold or italic because it can make the document harder to read.

## 6. Create Lists

Use bullet points or numbered lists when presenting several related items.

### Bulleted List Example

- First item
- Second item
- Third item

### Numbered List Example

1. Open the document.
2. Select the required text.
3. Apply the desired formatting.

Lists make information easier to scan.

## 7. Align Text Properly

Microsoft Word provides several alignment options:

- Left alignment
- Center alignment
- Right alignment
- Justified alignment

For most body text, left alignment is simple and easy to read.

## 8. Use Page Breaks

When starting a new section or chapter on a new page, use a page break instead of repeatedly pressing Enter.

To insert one:

1. Place the cursor where the new page should begin.
2. Open the **Insert** tab.
3. Select **Page Break**.

You can also use:

`Ctrl + Enter`

## 9. Add Headers and Footers

Headers and footers can contain useful information such as:

- Document title
- Section name
- Author information
- Page numbers
- Date

To add them:

1. Open the **Insert** tab.
2. Choose **Header** or **Footer**.
3. Select a suitable layout.
4. Add the required information.

## 10. Add Page Numbers

For longer documents, page numbers make navigation easier.

Go to:

**Insert → Page Number**

Choose a position and style that fits your document.

## 11. Use Tables When Helpful

Tables are useful for organizing structured information.

For example:

| Item | Status | Notes |
|---|---|---|
| Project A | Complete | Ready for review |
| Project B | In progress | More work required |
| Project C | Pending | Waiting for information |

Avoid using tables simply to create page layouts when normal Word formatting is more appropriate.

## 12. Check Document Consistency

Before finishing a document, check:

- Font consistency
- Heading styles
- Paragraph spacing
- Alignment
- Page numbers
- List formatting
- Margins
- Spelling and grammar

Consistent formatting gives the document a more professional appearance.

## 13. Use Word's Navigation Pane

If you use heading styles, the Navigation Pane can help you move through a long document.

Open it from:

**View → Navigation Pane**

You can then select headings to quickly move between sections.

## 14. Save Your Document

Use:

`Ctrl + S`

Save your document regularly to avoid losing changes.

For important documents, keep a backup copy in a trusted location.

## Quick Formatting Checklist

Before sharing a Word document:

- [ ] Use a readable font.
- [ ] Check font sizes.
- [ ] Apply heading styles.
- [ ] Review paragraph spacing.
- [ ] Check alignment.
- [ ] Use lists where appropriate.
- [ ] Add page numbers when useful.
- [ ] Check headers and footers.
- [ ] Review spelling and grammar.
- [ ] Save a final copy.

## Final Tip

Good document formatting should make information easier to understand.

Keep the design simple, use consistent styles, and avoid unnecessary formatting.
